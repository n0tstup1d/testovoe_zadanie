# Результаты проверки · 2 ноября 2026

## Автоматические проверки ядра

`node --test tests/core.test.cjs`: 9 тестов, все прошли.

- Названия предметов и смысловые темы; неизвестные запросы не порождают вымышленные объекты.
- Доступность всех 40 вариантов. Для каждого исходного path проверено сохранение точной строки геометрии в экспортируемом SVG.
- 90 сочетаний: S/L × 3 формата × 3 раскладки × 1–5 предметов. Проверены границы объектов и свободная область под заголовок.
- Проверка формата пользовательской палитры, перекраски и отсутствия объектных акцентов в фоне.
- Повторные объекты не создают дублирующиеся SVG ID. Экспорт одного состояния детерминирован.
- Собранная HTML-версия автономна, файлы manifest существуют.

## Интеграционная проверка в Chrome

`tests/browser.cjs`: прошёл сценарий генерации, неизвестного запроса, изменения координат/поворота/роли, дублирования, удаления и отмены, S/L и форматов, загрузки своей палитры, сохранения/восстановления проекта, перетаскивания мышью. Ошибок JavaScript не зафиксировано. Итоговый интерфейс проверен по скриншоту `examples/app-preview.png`.

Экспорт создаёт корректный векторный Blob и вызывает браузерное событие download. **Запись скачиваемого файла тестовым Chrome не подтверждена:** среда отменяет скачивание (`canceled`), в том числе отдельного минимального `data:text/plain,hello`, не связанного с приложением. Тест проверяет непосредственно содержимое создаваемого Blob. Фактическое скачивание следует проверить в обычном браузере пользователя.
