# GitHub и отправка работодателю

Проект подготовлен к публикации. Фактический репозиторий и сайт ещё не созданы.

## Вариант 1: публичный репозиторий + демо

Подходит, если код и предоставленные иллюстрации можно сделать общедоступными.

1. Создать на GitHub репозиторий `sobrano-illustration-composer` без добавления README или лицензии: они уже есть в проекте (лицензия на иллюстрации не назначается).
2. Загрузить **содержимое** этой папки в корень репозитория: `index.html` должен оказаться в корне, не внутри ещё одной папки.
3. В **Settings → Pages** выбрать **Deploy from a branch**, ветку `main`, папку `/(root)` и сохранить.
4. Дождаться опубликованного URL в Pages и проверить сайт по нему. Адрес будет формата `https://USERNAME.github.io/sobrano-illustration-composer/`, это шаблон, не готовая ссылка.
5. Отправить ссылку на сайт и на репозиторий. Дополнить короткой записью экрана по `DEMO.md` при необходимости.

Корневой `index.html` самодостаточен. `.nojekyll` отключает обработку Jekyll. После правок выполнить `npm run build`, чтобы обновились демо и плагин.

## Вариант 2: приватный репозиторий

Создать приватный репозиторий, загрузить файлы, предоставить работодателю доступ по её GitHub-логину. Для просмотра без установки отправить ZIP с проектом и указать открыть `demo.html`.

GitHub Pages на бесплатном тарифе доступен для публичных репозиториев. На тарифах, допускающих Pages из приватного репозитория, сам сайт обычно всё равно публичный — приватность исходников и сайта не одно и то же.

Официальная справка: https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages

## Перед отправкой

- Открыть опубликованное демо и проверить сборку, повторы, 3 варианта, закрепление и скачивание SVG.
- Запустить Figma-адаптер в Figma Desktop, если отправка заявляет его как проверенный плагин. Сейчас проверена браузерная версия, адаптер требует ручного прогона.
- Проверить, что репозиторий открывается у получателя.
- Заменить шаблоны ссылок в `SUBMISSION.md` реальными адресами. Не отправлять незаполненный шаблон.
