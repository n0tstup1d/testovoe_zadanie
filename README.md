# Собрано — конструктор векторных иллюстраций

Рабочий прототип тестового задания: сборка композиций из исходной библиотеки, ручная правка и экспорт SVG. Есть автономная демоверсия и адаптер для Figma.

## Быстрый запуск

Откройте **demo.html** в Chrome или Edge. Установка, сервер, интернет и API-ключи не нужны. Все 40 вариантов предметов и фоны встроены в файл.

1. Введите «Обучение онлайн» в режиме «По смыслу» или «книга, лампа, телефон» в режиме «По названиям».
2. Выберите формат, детализацию S/L, композицию и палитру. Нажмите «Собрать композицию». Сравните три миниатюры и выберите вариант.
3. Перетаскивайте предметы. В правой панели задавайте X/Y, поворот, роль; меняйте слои, дублируйте или удаляйте.
4. Нажмите «Скачать SVG». Для продолжения работы сохраните проект JSON.

## Запуск в Figma

Для импорта локального development-плагина требуется **Figma Desktop**. В браузерной Figma такой импорт недоступен.

1. Распакуйте проект в постоянную папку.
2. Откройте редактируемый дизайн-файл в Figma Desktop.
3. Меню **Plugins → Development → Import plugin from manifest…** → выберите `manifest.json`.
4. Запустите «Собрано — конструктор иллюстраций» из Development.
5. Соберите композицию → «Вставить в Figma». Каждый предмет импортируется из SVG как группа редактируемых векторных элементов.
6. После ручных правок в Figma выделите фрейм и нажмите **«Экспорт выделения Figma»**. Кнопка «Скачать SVG» экспортирует именно состояние предпросмотра, а не изменения на холсте Figma.

В manifest указан локальный development ID. Если Figma потребует собственный ID, создайте новый плагин через Development и перенесите выданный Figma `id` в этот manifest. Для публикации потребуется собственный ID.

Сборка и браузерная версия проверены автоматически. Запуск адаптера в реальном Figma Desktop ещё не проверен; перед отправкой работодателю нужен один ручной прогон импорта, вставки и экспорта.

## Что реализовано

- Два режима подбора: названия и смысловые правила для заголовков.
- Повтор названия создаёт отдельный экземпляр: «телефон, телефон, книга» → два телефона и книга. Повторы учитываются в лимите 5 предметов. Каждый экземпляр независимо сохраняет роль, поворот и порядок слоя при перестройке.
- 10 предметов × S/L × главная/фоновая роль = 40 исходных вариантов.
- Три формата: 1200×630, 1000×1000, 800×1200.
- Три схемы расположения: собранно, со смещением, место под заголовок; повторная раскладка.
- Сравнение трёх вариантов одновременно. Закрепление предметов: сохранение координат, общего масштаба, поворота и роли при перераскладке остальных.
- Редактирование: перенос, поворот, дублирование, удаление, порядок слоёв, смена роли, отмена.
- Три палитры, загрузка своей палитры JSON и автоматическая перекраска.
- SVG с исходными контурами и группами; сохранение и восстановление проекта JSON.
- Три готовых примера SVG и проекты к ним в `examples/`.

## Честные ограничения прототипа

- «По смыслу» — локальные словари и тематические правила, **не языковая модель**. Хорошо работает на темах библиотеки (учёба, финансы, команда, идеи, аудио, подарки). Произвольные сложные метафоры не гарантируются; неизвестный запрос сообщает об отсутствии совпадений.
- Автоматическая раскладка рассчитана на 1–5 предметов. Вручную можно собрать до 20. Она использует ограниченное семейство шаблонов; художественное качество требует пользовательской оценки.
- S/L назначены по размерам и визуальной детализации экспортов (8)/(9). Некоторые роли различаются геометрией: переключение использует готовый вариант, не модифицирует детали.
- Полнота библиотеки относительно упомянутых в ТЗ 20 исходных иллюстраций не подтверждена. Мы не добавляли отсутствующие изображения.
- После импорта в Figma поддерживается обычное редактирование; обратная синхронизация правок Figma в предпросмотр не реализована. Для их экспорта есть отдельная кнопка.
- Публикация на GitHub/Figma Community и размещение сервиса не выполнялись. Проект можно передать как запускаемый архив; для сдачи по ТЗ ещё нужна ссылка на репозиторий.

## Закрепление и варианты

Выберите предмет → «Закрепить предмет». «Сравнить 3 варианта» предлагает расположения остальных объектов, сохраняя закреплённый. Предмет нельзя случайно перетащить или повернуть, пока он закреплён; состояние сохраняется в JSON. Копия закреплённого предмета создаётся незакреплённой. Для смены формата, S/L или нового текстового запроса сначала открепите предметы. Перекраска остаётся доступной.

При большом количестве закреплений варианты могут совпадать. Свободная область под заголовок не гарантируется, если в ней уже закреплён предмет.

## Своя палитра

```json
{
  "backgroundTones": ["#D7CDF5", "#AA9BF0", "#7864D7"],
  "objectAccents": ["#F9ECB0", "#F9A3AA", "#FFE3E1"],
  "ink": "#181817",
  "paper": "#FFFFFF"
}
```

Внутри каждой тройки порядок соответствует исходной палитре. Первая тройка разрешена фонам и объектам; вторая — только объектам. `ink`/`paper` отвечают за контуры и нейтральные области предметов. Формат цветов — полный HEX `#RRGGBB`. В интерфейсе есть скачиваемый пример.

## Исходники и проверки

Для разработки нужен Node.js. Runtime-зависимостей нет.

```sh
npm run build
npm test
```

Опциональная интеграционная проверка браузера требует Playwright и установленный Chrome:

```sh
npm install --no-save playwright
node tests/browser.cjs
```

См. `ARCHITECTURE.md`, `VALIDATION.md`, `DEMO.md` и `AI-TOOLS.md`.

Материалы иллюстраций предоставлены пользователем для тестового задания. Права на них не переопределяются этим проектом.
